# Hermes Agent for macOS

A native macOS menu bar launcher for Hermes Agent — built to make a local AI agent dashboard easier to install, start, monitor, and use every day.

Hermes Agent for macOS bundles a Hermes Agent server source snapshot, starts the local dashboard on localhost, opens the browser UI, manages runtime bootstrap, stores provider credentials in Keychain, bundles official skills, and packages a drag-to-Applications DMG for testing.

> Built by OpenZen. The source code in this repository was generated by AI agent workflows under human direction, review, and product judgment. No source files were hand-written line by line by a human developer.

## Why this exists

Hermes Agent is powerful, but a local agent environment should not require users to remember terminal commands just to start a dashboard. This project gives Hermes Agent a Mac-native shell:

- guided first-run setup;
- local dashboard launch from the menu bar;
- runtime bootstrap for the current Mac;
- bundled skills;
- diagnostics and logs;
- clean uninstall path;
- universal Apple Silicon + Intel launcher binary.

## Highlights

- Native SwiftUI `MenuBarExtra` app.
- First-run wizard with install/uninstall choice, language, runtime source, data location, port, auth providers, skills, and launch preferences.
- Hermes runtime runner for `hermes dashboard --host 127.0.0.1 --port <port> --no-open --skip-build --tui`.
- Runtime bootstrap into `~/Library/Application Support/Hermes Agent/runtime` when a Python venv must be created for the current Mac/architecture.
- Bundled official Hermes skills.
- Provider authentication setup.
- Logs, diagnostics export, preferences, and clean uninstall.
- Universal launcher binary: `arm64 + x86_64`.
- Development DMG packaging with runtime smoke test, strict ad-hoc signing, and mount test.

## Security model

Hermes Agent for macOS is designed as a local-first launcher:

- dashboard listens on localhost;
- app data is stored in macOS Application Support;
- credentials configured through the launcher are stored in macOS Keychain;
- cloud model traffic happens only after the user configures and uses an external provider;
- runtime bootstrap is isolated inside the user data directory.

See `docs/SECURITY.md` for details.
