### Promotional Text

Start Hermes Agent from your Mac menu bar with guided setup, local dashboard launch, bundled skills, diagnostics, and universal Apple Silicon/Intel support.

### Description

Hermes Agent for macOS gives Hermes Agent a polished native launcher for Mac. It starts and monitors the local Hermes dashboard, opens the browser UI, manages data paths and ports, and keeps the control surface close in your menu bar.

The first-run setup flow helps you choose whether to install or remove Hermes Agent, pick the app language, select a runtime source, choose a data location, validate the local port, configure model access, and install official skills.

After setup, Hermes Agent stays out of your way until you need it. Open the dashboard, restart the local runtime, inspect logs, export diagnostics, change preferences, or uninstall cleanly from one Mac-native app.

Highlights:

- Native macOS menu bar launcher.
- Guided install and uninstall flow.
- Local Hermes dashboard startup.
- Runtime bootstrap for the current Mac.
- Apple Silicon and Intel launcher support.
- Official Hermes skills bundled.
- Custom data location and port.
- Provider authentication setup.
- Logs, diagnostics, and preferences.
- Light Openzen-branded interface.

Hermes Agent stores local app data in Application Support and uses the macOS Keychain for credentials configured through the launcher. The dashboard is opened on localhost. Cloud AI traffic is sent only to the model providers you choose and configure.

Hermes Agent is made for people who want a capable local AI agent environment on macOS with less setup friction and a cleaner daily workflow.
